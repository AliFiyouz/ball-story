# ball-story 🏀

یک بازی ساده‌ی «گرفتن توپ» با Canvas و JavaScript خالص.

## روش بازی
سبد زرد را حرکت بده و توپ‌های در حال سقوط را بگیر. هر توپ از دست‌رفته یک جان کم می‌کند؛ با ۳ جان بازی تمام می‌شود.

## امکانات
- امتیاز، ۳ جان، و افزایش تدریجی سرعت
- ذخیره‌ی رکورد در localStorage
- کنترل با ماوس، لمس (موبایل)، و کلیدهای ← →

## اجرا
فایل `index.html` را در مرورگر باز کنید.
